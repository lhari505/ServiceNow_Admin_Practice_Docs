# ServiceNow Journey – Day 1

## Objective
Learn how to create a ServiceNow Developer Account and request a Personal Developer Instance (PDI).

---

## Step 1: Sign Up for a ServiceNow Developer Account

Visit the ServiceNow Developer Portal:

https://developer.servicenow.com/dev.do

### Instructions
1. Open the ServiceNow Developer Portal.
2. Click **Sign Up**.
3. Create a new account using your email address.
4. Complete the registration form.

---

## Step 2: Verify Your Account

After submitting the registration form:

1. A verification code will be sent to your registered email address.
2. Enter the verification code.
3. Complete the verification process.
4. Log in to the Developer Portal.

### Expected Result
You will be redirected to the ServiceNow Developer Home Page.

---

## Step 3: Request a Personal Developer Instance (PDI)

After logging in:

1. Navigate to the top menu.
2. Click **Request Instance**.

**Alternative Path:**

- Start Building → Instance → Request Instance

---

## Step 4: Choose Instance Settings

You will see the instance setup screen.

### Configuration

- Select the latest ServiceNow release (for example: Washington, Xanadu, Zurich, or the latest available version).
- Select a region if required.
- Leave the default settings if you are unsure.

Click **Request**.

---

## Step 5: Wait for Instance Creation

ServiceNow will create your Personal Developer Instance.

### Instance Details Provided

- Instance URL
- Username (usually `admin`)
- Temporary Password

> Save the temporary password securely for future use.

---

## Step 6: Open Your Personal Developer Instance

1. Click **Open Instance**.
2. You will be redirected to the ServiceNow login page.

### Login Credentials

- **Username:** admin
- **Password:** Temporary Password

Click **Sign In**.

---

## Complete Workflow

```text
Sign Up
   ↓
Verify Email
   ↓
Login to Developer Portal
   ↓
Request Instance
   ↓
Wait for Provisioning
   ↓
Open Instance
   ↓
Login to PDI
   ↓
Start Practicing ServiceNow
```

---

## Day 1 Summary

By the end of Day 1, you should be able to:

- Create a ServiceNow Developer Account
- Verify your account successfully
- Request a Personal Developer Instance (PDI)
- Access your ServiceNow instance
- Log in as an Administrator
- Start exploring the ServiceNow platform
